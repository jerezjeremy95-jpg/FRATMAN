## Agente Astra
Agente de contenido para el equipo de Astra, hecho con skills, subagentes y comandos de Claude: Guardián de marca y claims, Reciclador de contenido y Guionista de Reels, con un modelo de Claude distinto según la tarea. Documentación, instalación y medición del riesgo: [`agente-astra/README.md`](agente-astra/README.md).

Instalación en Claude Code (un paso):
```
/plugin install agente-astra --marketplace jerezjeremy95-jpg/FRATMAN
```
