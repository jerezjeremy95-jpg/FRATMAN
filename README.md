## Lupa: detector de texto IA

Gratis, sin registro y sin límite de usos. Analiza hasta 50 000 palabras en el navegador con un modelo entrenado.

- `index.html`: la página final (generada; incluye los pesos del modelo).
- `src/index.src.html`: código fuente de la página.
- `model/`: entrenamiento del modelo, ver `model/README.md`.
- `ANALISIS.md`: cómo funciona JustDone, cómo funciona Lupa y su precisión medida.
- `.github/workflows/pages.yml`: despliegue automático en GitHub Pages.

Para activar GitHub Pages: Settings → Pages → Source: **GitHub Actions**.
